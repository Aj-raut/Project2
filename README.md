🚮 Clean Together App
Clean Together is a community-driven Android application designed to promote cleanliness and civic responsibility. It allows users to report, track, and view unclean areas in their locality using geo-tagged photos and real-time updates.

🌟 Features:
Report unclean spots with photo, description, and location

View reported areas on Google Maps

Track the status of cleaning reports

Firebase Realtime Database integration for data storage

Simple, user-friendly UI for easy navigation

🛠 Tech Stack:
Language: Java

UI: XML

Backend: Firebase Realtime Database

API: Google Maps API

📌 Purpose:
This project was built to encourage community participation in maintaining cleanliness and to provide local authorities or organizations with visibility into problem areas.
